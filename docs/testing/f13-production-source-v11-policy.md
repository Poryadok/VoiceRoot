substituted with H. For later events, F is derived as the first first-parent

## Complete units and every newly introduced commit

Every new DAG commit after F must descend from F and preserve the complete
Native projection, context, compiled closure, dependency directory inventories
and Voice tree. The separate complete Role unit and package inventories are
also preserved. Exact modes, types, object IDs, additions and deletions are
checked. All R records and evidence, historical source artifacts and exact K
carrier entries remain protected. Carriers cannot overlap runtime projection
or compiled inputs; any carrier context entry is explicitly bound to K.

These checks reject mutation followed by restoration, including side branches
and temporary package additions. A newly imported pre-F branch lies outside
this bounded reuse capability and needs a separately reviewed source contract.
That limitation does not assert a project-wide ban on such Git histories.

Changes outside these units receive no admission from H's evidence. They must
pass the genuine full collection and final fold from the collection base to S,
including original contribution gates, all actual owners, every best merge
base, accumulated runtime OR and guarded intermediate history. No cached
checkpoint or endpoint comparison substitutes for the actual producer.
